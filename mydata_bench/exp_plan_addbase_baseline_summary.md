# 新增 baseline 与原 attention steering 实验总结

## 1. 实验范围与口径

新增 **Robometer-4B、SOLE-R1-8B**，各比较五种输入，并测试原 target/non-target attention steering 的 k=8、32、64。Robometer 官方结构为“文本 → 图像”；SOLE 官方结构为“图像 → 文本”，采用自身历史的七步进度递归，并补充只干预末步的实验。

原生 baseline 使用完整 **1213 条（407 suc / 806 fail）**；attention 使用自动 grounding 的 **846 条（268 suc / 578 fail）**。以下 attention 均与自身同846条 baseline 比较。

准确率主阈值为 **0.125/0.875**，第二阈值为 **0.2/0.8**；低端严格小于下阈值，高端大于等于上阈值。五档 MAE 为进度分档至1–5后的绝对误差；连续 MAE 为 `mean(|1+4p−y|)`。无效输出计入准确率分母，MAE仅在有效数值上计算。

SOLE“文本 → 视频”有效1204/1213条，其余九项均为1213/1213条。SOLE使用greedy、max512，与官方随机解码默认不同；Meter保留官方读出，typed-softmax敏感性另见完整报告。

主要发现：

- **Robometer对输入顺序非常敏感。** 官方“文本 → 图像”总准确率31.57%，但suc为92.14%、fail仅0.99%，明显偏高分；“图像 → 文本”和“视频 → 文本”在两套端点阈值下均为0%，说明输出集中于中间进度，不能据此解释为所有连续评分都错误。
- **SOLE的官方图像输入表现最好。** “图像 → 文本”五档MAE为1.4378，总准确率42.46%；两种视频输入的总准确率约9%，明显更弱。
- **阈值影响很大。** 例如Robometer“文本 → 视频”总准确率由主阈值4.37%变为第二阈值25.97%，因此不能只看一套阈值或只看MAE。

## 3. 原 attention steering 结果（846条）

下表保留四个代表配置，均使用完整有效的baseline与target输出；MAE采用五档口径，准确率采用主阈值。SOLE两行均为完整七步干预。

| 模型 / 输入 | k | MAE：baseline → attention | 总准确率 | suc 准确率 | fail 准确率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Robometer-4B / 文本 → 图像 | 32 | 1.7695 → 1.0922 | 31.09% → 23.88% | 95.15% → 63.43% | 1.38% → 5.54% |
| Robometer-4B / 文本 → 视频 | 32 | 1.5626 → 1.1643 | 5.67% → 18.68% | 5.22% → 1.12% | 5.88% → 26.82% |
| SOLE-R1-8B / 图像 → 文本 | 64 | 1.3416 → 1.3050 | 44.33% → 46.45% | 30.97% → 32.09% | 50.52% → 53.11% |
| SOLE-R1-8B / 文本 → 图像 | 64 | 1.4125 → 1.3168 | 30.97% → 38.89% | 6.34% → 9.33% | 42.39% → 52.60% |

- **Robometer的MAE下降常伴随成功类准确率下降。** 官方图像输入k32使MAE下降0.6773，但suc下降31.72个百分点；视频输入k32也主要改善fail。
- **SOLE有小幅、较平衡的改善，但幅度不足。** 官方图像输入k64总准确率提高2.13个百分点；“文本 → 图像”k64提高7.92个百分点，均未达到10个百分点。
- **全部45个原attention target点中，通过完整目标的点为0。** Robometer、SOLE全七步、SOLE末步补充各15点，均没有同时满足完整覆盖、MAE下降、suc/fail提升及总准确率至少+10个百分点。

配对分析也有权衡：在543个同视频suc–fail配对中，SOLE官方输入k64的负序对从118降至104；Robometer官方输入k32的平均进度差虽增大，负序对却从11增至28。

## 4. 结论

**新增baseline和原attention实验均已完成尝试，但原attention没有在这两个模型上达到稳定有效目标。** 输入结构和阈值会明显改变分数分布；更关注目标区域、MAE更低，都不保证成功／失败判断同时变好。

SOLE视频输入还存在格式失败，例如全七步“文本 → 视频”k64有效809/846条，不能当作完整候选排序。其它k、末步实验、wrong/low控制、任务分布与top-8/32/64 head统计见[完整新增baseline报告](../results/mydata_bench/experiments_v2_addbase/session_20260908/final_added_baseline_report_v1/report.md)；历史记录见[原实验总结](exp_plan_addbase_summary.md)。
