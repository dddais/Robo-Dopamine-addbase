# Attention steering 方法探索实验总结

## 1. 目标与实验范围

目标是在四模型中至少三模型、每模型至少三种输入下，在同一已测k邻域内实现MAE下降、suc/fail准确率提高、总准确率至少 **+10个百分点**，并优于原attention。**目前尚无满足该目标且经过独立确认的方法。**

旧方法主要在grounded846条及其234/498分区探索。续研F1–F9覆盖Qwen3-VL-8B、RoboReward-8B、Robometer-4B各五输入；SOLE的全七步、末步及数值读出探索没有达到要求。F6–F9另用1942条、包含1–5全部等级的外部训练数据选头，493条作模型选择验证；后者不能替代原数据集的+10个百分点要求。

## 2. 已尝试的方法与结果

| 路线 | 做了什么 | 结果 |
| --- | --- | --- |
| 区域／时间差分 + 幅度、置信度或KL调节 | 比较加强／减弱ROI注意力的评分差，部分版本扣除重复首帧的静态响应，再修正原评分 | 部分输入改善明显，但原498确认整体失败。 |
| 原方法参照（anchor）与熵调节 | 在差分评分上混入原attention结果，用原生不确定性调整幅度 | 后续九项配置在846主阈值上观测通过；但复用了确认数据，且Meter第二阈值存在成功类下降，**不计为稳健成功**。 |
| F1–F2：逐帧概率搬运、叠加VCD噪声视觉对比 | 控制视觉注意力搬运量，或扣除受损视觉的评分响应 | 各完成15项旧234实验，稳定通过数均为0。 |
| F3–F5：区域特异性选头、任务文字与ROI联合增强、无任务语义参照 | 分别检验head排序、文字／视觉平衡与任务相关响应 | 各完成15项旧234实验，稳定通过数均为0。 |
| F6：仅评分query的监督梯度选头 | 用训练评分损失学习head排序及增强／减弱方向，保持原生读出 | 15项旧234均未通过；最好的primary总准确率增益仅3.85个百分点。 |
| F7：全query的CE梯度选头 | 将同类监督干预扩展到全部因果prefill query | 出现较大局部收益，但跨模型完整门槛失败。 |
| F8：累计有序损失选头 | 将CE替换为考虑评分等级顺序的损失 | 未改善完整通过范围。 |
| F9：样本等权的有序梯度选头 | 在F8基础上改用样本均值，按episode簇估计梯度不确定性 | RoboReward的493验证通过输入增多，但仍未通过原数据与验证的联合门槛。 |

F7–F9均固定 **b=1、k=32/48/64、primary=48**，排除前8层，使用训练得到的head及方向，模型骨干权重冻结。它们属于有监督选头，推理保留原生评分，不做端点赋值。

三种方案均完成各15项旧234和493评价。表内数字依次为 **Qwen / RoboReward / Robometer** 的通过输入数，每模型共五种输入。

| F7 | 1 / 0 / 0 | 0 / 3 / 0 | 0 / 0 / 0 |
| F8 | 1 / 0 / 0 | 0 / 2 / 0 | 0 / 0 / 0 |
| F9 | 1 / 0 / 0 | 0 / 4 / 0 | 0 / 0 / 0 |

原234唯一稳定通过的输入始终是 **Qwen“视频 → 文本”**。通过要求三个k、两个baseline以及same-k和较强原attention比较全部满足；Robometer同时检查两套阈值。493检查全等级MAE／准确率改善及端点不退化。

- **Qwen“视频 → 文本”是最稳定的局部结果**：三种方案分别提升20.51、18.38、19.23个百分点，但在493上均未通过完整验证，不能外推为跨数据稳定有效。

## 4. 主要结论

1. **换输入、增强ROI或重新选头能明显改变评分，但收益依赖模型和输入。** 目前没有形成三模型各三输入的稳定改善。
2. **损失下降不等于评分更准确。** F9在Qwen“文本 → 视频”的完整训练诊断中，有序损失下降，但准确率38.52% → 37.85%、MAE 1.0427 → 1.1030；改损失和样本权重仍不足以解决问题。
3. **旧差分／熵方案只保留为探索结果。** 原确认失败后复用498继续改方法，不能支持独立泛化结论。F7–F9未满足前置门槛，因此没有运行完整846扩展和2831保留测试；保留测试奖励表现尚未打开。
