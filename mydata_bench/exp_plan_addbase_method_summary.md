# Attention steering 方法探索实验总结

单独方法记录：[区域差分法](method_region_contrast.md)、[其他候选方法与结果](method_alternative_candidates.md)（按2026-09-13放宽口径整理）。

## 1. 目标与实验范围

此前严格目标是在四模型中至少三模型、每模型至少三种输入下，在同一已测k邻域内实现MAE下降、suc/fail准确率提高、总准确率至少 **+10个百分点**，并优于原attention。**尚无满足该严格目标且经过独立确认的方法。** 第1–4节保留该口径；第5节按2026-09-13用户放宽幅度和输入数量后的要求重新汇总。

旧方法主要在grounded846条及其234/498分区探索。续研F1–F9覆盖Qwen3-VL-8B、RoboReward-8B、Robometer-4B各五输入；SOLE的全七步、末步及数值读出探索没有达到要求。F6–F9另用1942条、包含1–5全部等级的外部训练数据选头，493条作模型选择验证；后者不能替代原数据集的+10个百分点要求。

## 2. 已尝试的方法与结果

| 路线 | 做了什么 | 结果 |
| --- | --- | --- |
| 区域／时间差分 + 幅度、置信度或KL调节 | 比较加强／减弱ROI注意力的评分差，部分版本扣除重复首帧的静态响应，再修正原评分 | 部分输入改善明显，但原498确认整体失败。 |
| 原方法参照（anchor）与熵调节 | 在差分评分上混入原attention结果，用原生不确定性调整幅度 | 后续九项配置在846主阈值上观测通过；但复用了确认数据，且Meter第二阈值存在成功类下降，**不计为稳健成功**。 |
| F1–F2：逐帧概率搬运、叠加VCD噪声视觉对比 | 控制视觉注意力搬运量，或扣除受损视觉的评分响应 | 各完成15项旧234实验，稳定通过数均为0。 |
| F3–F5：区域特异性选头、任务文字与ROI联合增强、无任务语义参照 | 分别检验head排序、文字／视觉平衡与任务相关响应 | 各完成15项旧234实验，稳定通过数均为0。 |
| F6：仅评分query的监督梯度选头 | 用训练评分损失学习head排序及增强／减弱方向，保持原生读出 | 15项旧234均未通过；最好的primary总准确率增益仅3.85个百分点。 |
| F7：全query的CE梯度选头 | 将同类监督干预扩展到全部因果prefill query | 出现较大局部收益，但跨模型完整门槛失败。 |
| F8：累计有序损失选头 | 将CE替换为考虑评分等级顺序的损失 | 未改善完整通过范围。 |
| F9：样本等权的有序梯度选头 | 在F8基础上改用样本均值，按episode簇估计梯度不确定性 | RoboReward的493验证通过输入增多，但仍未通过原数据与验证的联合门槛。 |

F7–F9均固定 **b=1、k=32/48/64、primary=48**，排除前8层，使用训练得到的head及方向，模型骨干权重冻结。它们属于有监督选头，推理保留原生评分，不做端点赋值。

## 4. 主要结论

1. **换输入、增强ROI或重新选头能明显改变评分，但收益依赖模型和输入。** 目前没有形成三模型各三输入的稳定改善。
2. **损失下降不等于评分更准确。** F9在Qwen“文本 → 视频”的完整训练诊断中，有序损失下降，但准确率38.52% → 37.85%、MAE 1.0427 → 1.1030；改损失和样本权重仍不足以解决问题。
3. **旧差分／熵方案只保留为探索结果。** 原确认失败后复用498继续改方法，不能支持独立泛化结论。F7–F9未满足前置门槛，因此没有运行完整846扩展和2831保留测试；保留测试奖励表现尚未打开。

完整逐输入／逐k结果见[F7–F9结果详表](auto_research_addbase/F7_F8_F9_COMPLETE_RESULTS_20260912.md)，早期路线见[续研协议与记录](auto_research_addbase/ROBUST_RESEARCH_PROTOCOL_20260909.md)，旧方案的确认复用问题见[有效性核查](auto_research_addbase/METHOD_VALIDITY_AUDIT_20260910.md)。

## 5. 放宽门槛后的结论（2026-09-13）

不要求+10个百分点、不要求多种输入；每模型允许选择一个输入和已测k，仍要求完整覆盖、MAE下降、suc/fail准确率均提高。以下先统计**优于自身baseline**，对连续读出同时核对原两套端点阈值；超过原attention的情况另行说明。这是对旧结果的回顾性整理，不是新的独立确认。

**区域差分家族的覆盖最广：三个模型有498条结果，SOLE另有60条初筛正收益。** 核心为 `z_new = z_baseline + λ(z_ROI+ − z_ROI−)`，所有原生评分档位保留；四行均为区域差分，但输入、k、λ及ROI作用范围不同。下表箭头均为同数据、同读出baseline → 方法，准确率采用原主阈值。

| 模型 / 输入 | 样本数 | MAE | 总准确率 | suc准确率 | fail准确率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Qwen / 文本 → 视频 | 498 | 1.4177 → 0.9378 | 14.86% → 49.60% | 41.77% → 67.72% | 2.35% → 41.18% |
| RoboReward / 文本 → 图像 | 498 | 1.5361 → 0.9177 | 19.08% → 50.00% | 50.00% → 51.90% | 4.71% → 49.12% |
| Robometer（progress head）/ 图像 → 文本 | 498 | 2.2553 → 1.0424 | 0.00% → 46.99% | 0.00% → 33.54% | 0.00% → 53.24% |
| SOLE / 视频 → 文本 | **60初筛** | 2.1020 → 2.0613 | 11.67% → 20.00% | 30.00% → 35.00% | 2.50% → 12.50% |

对应b均为3：Qwen k48/λ4/末帧ROI，RR k48/λ2/全帧ROI，Meter k68/λ64/全帧ROI，SOLE k64/λ8/全帧ROI。前三行来自最初冻结配方的498条结果；SOLE使用固定原生历史与reasoning的末步201整数评分分布，没有完成该方案的完整846条评价。Meter/SOLE表内MAE为连续ordinal MAE，Qwen/RR为原生1–5 MAE。

- **不能把以上写成四模型完整验证成功。** SOLE仅增加5条正确预测，原来因增益8.33个百分点未达到+10门槛而没有扩展；现在值得作为候选保留。RR这一行虽改善自身baseline和同k原attention的MAE/总准确率，但fail准确率未超过同k原方法，也未超过较强原attention。
- **F9也有三模型局部有效结果，且统一使用b=1、k=48。** Qwen“视频→文本”总准确率23.93% → 43.16%，RR交错输入17.52% → 32.05%，Meter“文本→视频”5.13% → 18.38%；三者在旧234上均降低MAE、提高两类准确率，Meter两套阈值均成立。SOLE未做F9；所列Qwen和Meter配置在493上未保持完整改善。
- 完整扫描F1–F9后，按上述baseline口径，**F2/F6/F9各覆盖3个模型，F1/F3/F7/F8各覆盖2个，F4/F5为0**。这些路线均只评估Qwen/RR/Meter，不能把SOLE未评估当作已证明无效。再要求优于同k及较强原attention的MAE/总准确率，F6–F9均只剩Qwen，F1–F5为0。
- **上述Robometer改进证据均针对progress head。** F9已检查的保存预测没有success输出；之前补齐success head的是原attention实验，不能替代改进方法在success head上的验证。
